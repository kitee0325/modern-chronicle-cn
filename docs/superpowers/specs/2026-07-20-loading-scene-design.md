# 页面启动 Loading 场景设计

## 目标

在应用内容出现前提供一段简洁、克制、与现有 Figma 场景稿一致的启动动画。当前使用模拟加载进度，后续可无缝替换为图片、音频等真实资源的加载进度。

全站文字统一使用用户提供的“方正大标宋简体”本地字体，并保留系统中文字体作为加载失败时的兜底。

## 视觉方向

- 使用设计稿中的低饱和现代城市叙事：米白底色、深棕轮廓、灰蓝建筑、墨绿进度强调和少量浅粉点缀。
- 页面保留大面积留白，不使用卡片、玻璃效果、霓虹、复杂纹理或高频装饰。
- 中央主体是一条横向城市天际线，底部轨道同时承担进度基线。
- 下方仅保留百分比和“城市记忆正在展开”状态文案。
- 桌面端保持宽阔横向构图；窄屏按比例缩小主体并隐藏最边缘的次要建筑，避免拥挤。

## 动效叙事

加载进度从 0 到 100 平滑推进，列车本身就是进度指示器：

1. 页面进入时，米白背景先显现，轨道线从左向右展开。
2. 列车沿轨道从左向右行驶，其水平位置直接映射当前加载百分比。
3. 列车经过各个进度阈值时，对应建筑依次从轨道下方“冒出”：先上移并淡入，再以很小幅度回落稳定；建筑之间错开约 70–110ms。
4. 建筑出现后保持静止，仅允许极轻微的明暗呼吸，不做持续漂浮或弹跳。
5. 百分比随进度更新；状态文案保持稳定，避免与主体争抢注意力。
6. 到达 100% 后，列车轻缓刹停约 300ms，完整城市轮廓停留约 350ms；随后 Loading 整体淡出并轻微上移，主页面同步淡入。

动画使用缓出曲线，避免机械匀速和夸张弹簧。开启 `prefers-reduced-motion` 时取消建筑弹性、呼吸和位移，仅保留短淡入淡出与进度数值更新。

## 组件与职责

### `AppLoading`

- 接收 `progress`、`isComplete` 和可选状态文案。
- 负责覆盖层、百分比、退场状态与无障碍属性。
- 使用 `role="progressbar"`，提供 `aria-valuemin`、`aria-valuemax` 和 `aria-valuenow`。

### `LoadingCity`

- 渲染轨道、列车和简化城市轮廓。
- 每栋建筑声明自己的出现阈值；根据当前进度切换可见状态。
- 列车位置由进度派生，不维护第二套动画进度，避免视觉与数字不同步。

### `useSimulatedProgress`

- 当前阶段生成平滑模拟进度。
- 前段推进稍快，中段平稳，90% 后放慢，最终自动完成。
- 暴露与真实资源加载一致的 0–100 数值边界；后续替换数据来源时，UI 组件无需修改。

### 全局字体

- 将提供的 TTF 文件纳入项目字体资源，通过 `@font-face` 声明。
- 在 `:root`、表单控件和按钮统一使用该字体。
- 设置 `font-display: swap`，并以常见中文衬线字体和系统字体兜底。

## 状态流转

`loading` → `settling` → `exiting` → `content`

- `loading`：模拟进度推进，列车和建筑联动。
- `settling`：进度达到 100%，短暂停留展示完整画面。
- `exiting`：覆盖层退出，主内容开始进入。
- `content`：从 DOM 移除 Loading，避免它继续拦截交互。

开发环境中的 React Strict Mode 可能重复执行副作用；进度计时器必须正确清理，确保不会出现双计时器或卸载后更新状态。

## 异常与降级

- 字体加载失败时使用本地中文衬线字体兜底，不阻塞页面进入。
- 模拟加载不依赖网络请求；未来真实资源加载失败时应允许以已完成或降级状态结束，不能永久卡在 Loading。
- 页面切到后台时，浏览器可能降低计时器频率；恢复后以当前时间重新计算进度，避免大量补帧。
- 动画不可用或用户要求减少动态效果时，页面仍显示清晰的百分比和状态文案。

## 验收标准

- 首次进入时 Loading 覆盖整个视口，不闪现后方内容。
- 列车位置、百分比和加载状态始终一致。
- 建筑按列车经过的顺序逐个出现，而不是同时播放。
- 100% 后完成停留与退场，主页面可正常交互，覆盖层已移除。
- 320px 宽手机到常见桌面视口均无横向滚动、裁切或文字重叠。
- 全站文字及表单控件优先使用方正大标宋简体。
- `prefers-reduced-motion` 下无明显位移、弹跳或持续呼吸。
- TypeScript 构建和 ESLint 检查通过。

## 非目标

- 本次不接入真实资源清单、预加载管理器或失败重试界面。
- 不新增路由、全局状态库或第三方动画依赖。
- 不复刻 Figma 中某一整幅场景，只提取其配色、城市轮廓和叙事语言。
